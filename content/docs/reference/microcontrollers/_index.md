TinyGo lets you run Go directly on microcontrollers.

TinyGo has support for over 150 different boards and devices such as the [Adafruit Circuit Playground Express](./featured/circuitplay-express), [BBC micro:bit](./boards/microbit), [Raspberry Pi Pico](./featured/pico), [Seeed Studio XIAO-ESP32C3](./featured/xiao-esp32c3) and many others.

We also give you the ability to add new boards. For more information, please see [our contribution guide](../../guides/contributing/#some-specific-hardware-you-want-to-use-does-not-appear-to-be-in-tinygo).
